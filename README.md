# Winter Spirit Week Race

A 40-space board for the pep rally. Four grades (9th pink, 10th purple, 11th green, 12th red) race gingerbread pawns to the Candy Castle. Use +1 / +5 to move a grade forward and −1 to undo a mistake.

Live site: https://tachyonzzz.github.io/winter-spirit-week/

Everything is in `index.html`. Positions are saved in the browser that's running the board, so run it from the same laptop all event.
